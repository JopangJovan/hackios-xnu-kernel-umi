# HakiOS

[English](README.md) · [中文](README.zh.md) · Українська

HakiOS — це адаптація ядра Darwin (відкритий XNU від Apple, xnu-8796.121.2) до Android-телефонів із Qualcomm, так
само як Android — адаптація Linux до телефонів: власний завантажувач, власні драйвери, система конфігурацій
(`configs/`) і власна версія ядра (`VERSION`). Те саме працює в QEMU (`virt`, aarch64) на комп'ютері з Linux, без
нічого від Apple і без нічого з будь-якого телефона (`make qemu-open`).

Тут три шари, і проєкт каже, за який із них він відповідає (`LEGAL.md`):

1. **Відкрите ядро**: порт ядра, завантажувач, драйвери, інструменти. Увесь код у цьому репозиторії.
2. **Те, що ви кладете зверху**: ядро може запустити користувацький простір, який ви надаєте самі. Проєкт збудовано
   так, що воно вміє запускати користувацький простір iOS 16.5, який ви самі збираєте з файлів, завантажених у
   Apple; проєкт нічого з цього не поширює і нічого не обходить, щоб це отримати. Чи можна вам це робити і чи
   хочете ви — ваше рішення.
3. **Сервіси Apple** (активація, Apple ID, iCloud, App Store): не підтримуються і не є метою.

За замовчуванням завантажувач іде в ОЗП через `fastboot boot`, система живе в ОЗП до кінця сеансу, а
перезавантаження повертає телефон у його власний Android. Єдине, що він пише за замовчуванням, — власний журнал
(кілька КБ) у розділ `logdump` телефона; з `ufs_write=1` ядро пише лише в розділ `darwin`, який ви створюєте самі.
Це дослідницький стенд, а не прошивка.

Докладніше: [`COMMUNITY.md`](COMMUNITY.md), [`docs/configs.md`](docs/configs.md), [`docs/versioning.md`](docs/versioning.md),
[`docs/boot-args.md`](docs/boot-args.md), [`docs/uefi-boot.md`](docs/uefi-boot.md), [`docs/install.md`](docs/install.md),
[`docs/comparison.md`](docs/comparison.md), [`drivers/README.md`](drivers/README.md).

Перший телефон — **POCO X5 Pro 5G** (`redwood`, Snapdragon 778G). Ядро нічого не знає про нього
наперед: кожна адреса, переривання, лінія живлення і прошивка беруться з дерева пристроїв самого
телефона та його Android, тож порт на інший телефон Qualcomm — це новий каталог у `devices/`, а
не переписування.

## Що є в репозиторії

Лише мій код і мої дані:

- ядро: патч до відкритого XNU від Apple (`xnu/hakios.patch`, APSL 2.0) і мої файли драйверів
  (`xnu/files/`, `drivers/`), які `xnu/apply.sh` накладає на свіжий клон;
- завантажувач (`xnuloader/`), мої програми й бібліотеки (`userland/src/`), інструменти
  (`tools/`), скрипти збірки та запуску;
- `prebuilt/`: ядро, завантажувач і бібліотеки, зібрані з цього репозиторію;
- `devices/redwood/`: те, що потрібно одному телефону (порт UEFI, дерево пристроїв, скрипт прошивок).

Чого немає і не буде:

- жодного файлу iOS: ні бінарників, ні образів, ні кешів, ні шрифтів, ні картинок, ні знімків
  екрана. Образ системи ви збираєте на своїй машині з IPSW iOS 16.5, який `sysimage/fetch.sh`
  завантажує з публічних серверів Apple, нічого не розшифровуючи й не обходячи;
- прошивок телефона (GPU, Wi-Fi, аудіо-DSP, модем, вібро, камери): вони вендорські і знімаються
  з вашого власного телефона в `fw-*/`, які git ігнорує;
- ключів, сертифікатів, активації чи будь-чого, що видавало б телефон за iPhone перед службами
  Apple. Вхід в обліковий запис Apple тут неможливий і не є метою.

## Швидкий старт у QEMU

Linux x86-64, близько 12 ГБ на диску, 7-Zip 23 або новіший, `lz4`, `qemu-system-aarch64`, `edk2-aarch64`.

```sh
git clone https://github.com/oosexgang/hackios-xnu-kernel.git hakios
cd hakios
make doctor       # чого бракує цьому комп'ютеру (дисплей QEMU, UEFI, пам'ять) і що робити
make fetch        # IPSW iOS 16.5 із серверів Apple, потрібне розпаковується (7,4 ГБ)
make images       # образи APFS: userland/root.apfs і userland/system.apfs
make qemu         # сеанс на 20 хвилин
```

**Що ви побачите.** Процесор емульований, тож повільно, а вікно спочатку **чорне**: це нормально. Перша-друга хвилина
чорного екрана, потім логотип Apple, потім екран блокування приблизно за 3–10 хвилин залежно від комп'ютера. Миша з
затиснутою кнопкою — палець; `H` — «Додому», `L` — кнопка живлення, `↑`/`↓` — гучність.

**Якщо екран лишається чорним:** (1) `tail -f logs/qemu.log` в іншому терміналі: за секунди має з'явитись
`== XNULOADER v3 ==`, далі рядки ядра і launchd; якщо порожньо — запустіть `make doctor`; (2) `qemu/screendump.sh` зберігає
те, що показує екран гостя (`logs/qemu-screen.png`), що б не робило вікно; (3) якщо вікна немає або воно чорне, а журнал
іде — у вашому QEMU може не бути GTK (WSL без WSLg): `qemu/run-ios.sh 1200 -display vnc=127.0.0.1:0` і VNC-клієнт на
`127.0.0.1:5900`; (4) гість просить у QEMU 7 ГБ пам'яті (мінімум 6): на меншій пам'яті все дуже повільно.

## На телефоні

Телефон, для якого є порт (`devices/redwood/`, POCO X5 Pro 5G), з розблокованим завантажувачем,
`adb` і `fastboot` на комп'ютері, образи з попереднього розділу і прошивки самого телефона:

```sh
make firmware                       # GPU, Wi-Fi, звук/батарея, вібро, модем, камери -> fw-*/
make phone                          # 10-хвилинний сеанс з усім залізом, потім назад в Android
make phone ARGS="modem=1" SECS=300  # або свій набір параметрів ядра
```

Головні параметри ядра (повний список — у `docs/ru/notes.md`):

| Параметр | Що дає |
|---|---|
| `cpus=8 bootcpu=7 cpufreq=1` | усі ядра процесора та їхні частоти |
| `touchscreen=1` | сенсорний екран |
| `gpu=1` | малювання на Adreno (образ, зібраний з `GL=1`, прошивки у `fw-gpu/`) |
| `adsp=1 sound=4 mic=4` | аудіо-DSP: динаміки, мікрофон; з ним же батарея та заряджання |
| `haptic=5` | вібромотор |
| `wifi=1` | Wi-Fi (мережа з `fw-wifi/network`) |
| `cam=5` | камери |
| `modem=1` | модем поруч із системою: його прошивка, файлові системи, IPA, SIM, NAS |
| `var_store=1 ufs_write=1` | зберігати `/private/var` між перезавантаженнями |

## Збірка з вихідників

```sh
make kernel       # XNU з GitHub Apple + мої зміни -> xnu-src/, залежності, збірка
make loader       # завантажувач; identity.h робиться при збірці з вашого IPSW
make images       # користувацький простір і образи
```

Подробиці: `xnu/README.md`, `docs/ru/notes.md`.

## Структура

| Каталог | Вміст |
|---|---|
| `xnu/` | патч і файли ядра; `apply.sh`, `export.sh`; README про ядро |
| `drivers/*/hakios.*` | мої драйвери: екран, тач, UFS, GPU, Wi-Fi, звук, модем, SIM/NAS, вібро, камери |
| `xnuloader/` | завантажувач (застосунок UEFI) |
| `userland/` | мої програми й бібліотеки (`src/`), збірка образів, завдання launchd |
| `sysimage/` | скрипти, що беруть і розпаковують файли ОС з IPSW (самих файлів немає) |
| `devices/redwood/` | один телефон: його порт UEFI, дерево пристроїв, готові образи UEFI, скрипт прошивок |
| `tools/` | APFS, прошивки, тести QMI, скрипти прогонів |
| `qemu/` | запуск у QEMU |
| `docs/` | `cellular.md` — зв'язок (англійською); `ru/` — докладний щоденник розробки російською |
| `prebuilt/` | зібрані ядро, завантажувач, бібліотеки |
